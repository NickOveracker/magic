Simulation (IRSIM)

irsim [prm] [cell] extracts the cell if needed, writes its .sim, starts IRSIM (loaded only now) and gives you its irsim> prompt: h, l, s, d, ana and the other IRSIM commands. A cell whose supplies aren't named Vdd and Gnd needs them driven first, e.g. h VDD and l GND. Type . to return to Magic, where simcmd d applies an IRSIM command to the selection, watchnode labels the selected node with its value, and the rsim tool (space) shows node values on a middle click. q at the prompt quits IRSIM. Options > IRSIM has the analyzer and node lists.

Checking against a schematic (LVS)

lvs [schematic [cell [setup]]] extracts the cell in the window (ext2spice lvs) and compares it with a schematic netlist in the project (add one with Project > Add files to project), using netgen (loaded only now): it checks that the layout implements the same circuit, device for device and net for net. Without arguments it takes the project's netlist with "sch" in its name and netgen's setup for scmos. The Result window shows what differs; the report is saved as comp.out. Options > LVS against a Schematic does the same with a dialog. The cell's pins must be ports (port makeall) for netgen to match them. Each demo comes with its schematic; Stixu's layouts have no n-well contacts, so their wells float and LVS says so, while the "n-well contact" inverter matches.

Options > Open in the IRSIM App and Open in the netgen App extract the cell in the window and open the IRSIM or netgen web app in a new tab with it: IRSIM simulates its .sim (running <cell>.cmd, if the project has one), netgen compares it with the schematic lvs would choose. The files pass from tab to tab in the browser.

Projects

Project > Open files or Open folder copies .mag files, a folder, or one .zip, .tar or .tar.gz archive into the page; you can also drop them on it. The cell that no other cell uses is opened. A .tech file in the project is loaded first; otherwise the technology the cell names (scmos is built in).

To keep your work, either work in a folder on disk (Chrome, Edge and other Chromium browsers: every file Magic writes, for example with File > Save All or the w key, goes straight into that folder) or keep the project in browser storage (any browser; private to this site). Both appear under Project > Recent next time. Otherwise files live in memory until you download them as .tar.gz.

シミュレーション（IRSIM）

irsim [prm] [cell] は、必要ならセルを抽出して .sim を書き出し、IRSIM を起動して（読み込むのはこの時です）、 irsim> プロンプトを出します。h、l、s、d、ana などの IRSIM のコマンドが使えます。電源の名前が Vdd と Gnd でないセルは、先に電源を駆動する必要があります（例：h VDD と l GND）。. と入力すると Magic に戻ります。Magic では、 simcmd d で選択したものに IRSIM のコマンドを適用し、watchnode で選択したノードに値のラベルを付け、rsim ツール（space）では中ボタンのクリックでノードの値を表示します。プロンプトで q と入力すると IRSIM を終了します。「オプション」>「IRSIM アナライザー」「IRSIM ノードリスト」もあります。

回路図との照合（LVS）

lvs [schematic [cell [setup]]] は、ウィンドウのセルを抽出し（ext2spice lvs）、プロジェクト内の回路図のネットリスト（「プロジェクト」>「プロジェクトにファイルを追加」で追加できます）と netgen で比較します（netgen を読み込むのはこの時です）。レイアウトが同じ回路を、素子ごと、ネットごとに実現しているかを調べます。引数なしでは、名前に「sch」を含むプロジェクトのネットリストと、 netgen の scmos 用セットアップを使います。違いは結果ウィンドウに表示され、レポートは comp.out に保存されます。「オプション」>「回路図との LVS…」でも、ダイアログから同じことができます。netgen がピンを対応付けられるよう、セルのピンはポート（port makeall）にしておく必要があります。どのデモにも回路図が付いています。Stixu のレイアウトには n ウェルのコンタクトがないため、ウェルが浮いていると LVS に指摘されますが、「n ウェルコンタクト付きインバーター」は一致します。

「オプション」>「IRSIM アプリで開く」と「netgen アプリで開く」は、ウィンドウのセルを抽出し、IRSIM または netgen のウェブアプリを新しいタブで開いて渡します。IRSIM はその .sim をシミュレーションし（プロジェクトに <cell>.cmd があれば実行します）、 netgen は lvs が選ぶ回路図と比較します。ファイルはブラウザー内でタブからタブへ渡されます。

プロジェクト

「プロジェクト」>「ファイルを開く」または「フォルダーを開く」で、.mag ファイル、フォルダー、または .zip、.tar、.tar.gz のアーカイブ 1 つをページにコピーします。ページにドロップすることもできます。ほかのどのセルからも使われていないセルが開かれます。プロジェクトに .tech ファイルがあれば先にそれを読み込み、なければセルが指定するテクノロジーを読み込みます（scmos は組み込みです）。

作業内容を残すには、ディスク上のフォルダーで作業する（Chrome、Edge などの Chromium 系ブラウザー。「ファイル」>「すべて保存」や w キーなどで Magic が書き出すファイルは、すべてそのフォルダーに直接保存されます）か、プロジェクトをブラウザーのストレージに保存します（どのブラウザーでも可。このサイト専用）。どちらも次回、「プロジェクト」の最近のプロジェクトに表示されます。そうしない場合、ファイルは .tar.gz としてダウンロードするまでメモリ上にだけあります。
